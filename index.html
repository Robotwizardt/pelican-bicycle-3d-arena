耗时按首尾消息时间戳之差计算，含工具调用与等待时间（四者合计 269.5 min ≈ 4.5 h）。 长上下文反复重发导致缓存读取占了总量的 85%–96%， 因此「总 token」看着很唬人；「非缓存 token」= input + output，更接近模型真正处理的新内容量。 step-5-preview 的 74.1 min 是纯建站任务耗时，之后用户又追问了 3 轮 CDN 发布原理，整段会话为 238.6 min。

费用口径：按各模型官方价目表单价（StepFun $1 / $2.70 / $0.05，OpenAI $10 / $50 / $1， Anthropic $4 / $20 / $0.20，均为 输入 / 输出 / 缓存读，单位美元每百万 token）乘以实际 usage 计算， 不等于实际账单 —— 四个模型里只有 step-5-preview 直连官方端点， gpt-6-astra 和 claude-opus-5-5 走 api.laogou.org 中转， cn:deepseek-v4.1-flash 走本地代理。官方单价与本地 models.json 登记的 cost 完全一致，交叉验证通过。 四个会话的单请求最大 prompt 为 96K / 69K / 109K / 86K，均未触发长上下文加价档。

三个特殊点： ① DeepSeek 官方以人民币计价且分峰谷（工作日北京时间 9:00–12:00、14:00–18:00 翻倍）， 该会话只有 17:56–17:59 这 3.4 分钟落在高峰，已逐条拆开计价，折算汇率取 ¥1 = $0.15。 ② claude-opus-5-5 的费用是手算的：它的 provider cost 配置在会话末尾才补上， transcript 里 93 次请求的费用记录全是 0。 ③ 「含子代理」列包含 gpt-6-astra 的 3 个子代理、claude-opus-5-5 的 7 个子代理 —— 后者那 6 轮视觉审查实际跑在 cn:glm-5.3 上，是另一个模型的钱。 完整拆分见 README.md。
