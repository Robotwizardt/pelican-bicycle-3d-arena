第二批（5–8）口径： 这四个是同日 12:39 → 15:56 UTC 另跑的一轮，prompt 多了三条约束：写死落点路径（pages/ 里）、不许读前面四个的成果、发布直接推到本仓库。 它们的费用不取自官方价目表，而是直接汇总各 provider 在 transcript 里记账的 cost —— cn:hy4-preview 走本地代理、grok-4.7 走 api.laogou.org 中转， 与第一批（统一按官方单价重算）口径不同，两批之间不要横向比价，只跟同批比。 hy4-preview 净 token 高达 1091 万，是因为它的网关几乎没命中缓存（input 1047 万才配对 485 万缓存读），这也直接把它的费用顶到 $10.03。 四个新会话里 cc/gpt-6-sol 另有 10 + 7 次 0 token 的空调用（编排用，无计费），已并入轮次外不计。

第三批（9）口径： 一天后用逐字相同的第二批 prompt 补跑的一个，落点 pages/pelican-bicycle-3d-cn-glm-5.3/ （模型名里的冒号被它自己洗成了连字符——Windows 目录名不允许 :）。 prompt 里那句「已经做过四版、另外四个文件夹」早就过时了（当时实际有 8 个），它没被误导： 其他 8 个页面的目录名在整份会话里一次都没出现过。 费用同样是 provider 记账（workbuddy）：cn:glm-5.3 登记单价 $1.4 / $4.4 / $0.26，逐条相乘后分毫不差，$0.77 + $0.62 + $2.61 = $3.99。 只有 1 条用户消息、245 轮，缓存命中 93.6%。
