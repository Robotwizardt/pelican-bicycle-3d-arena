# Pelican on a Bicycle · 3D Arena

> 模型：`kimi-k2.8-preview` · 纯前端 · 无构建步骤 · 直接打开 `index.html` 即可

一只鹈鹕在海边木板路上骑自行车的完整 3D 场景。

## 直接打开

无需构建、无需服务器。双击 `index.html`，或任意静态服务器托管本目录即可。
（`file://` 下个别浏览器对 ES Module 有限制，若空白请用本地服务器，如 `python -m http.server`。）

## 技术亮点

| 能力 | 实现 |
|------|------|
| 3D 渲染 | Three.js r160（已本地化到 `vendor/`，无 CDN 依赖） |
| 逐顶点动画 | 自研 GPU 蒙皮：把每段肢体包成"蒙皮盒"，顶点在 vertex shader 里按盒内位置做关节旋转，替代骨骼网格 |
| 自定义 GLSL | ① 天空穹顶着色器（渐变 + 太阳 + 星星 + 昼夜过渡）；② 海面着色器（3 波 Gerstner 顶点位移 + 程序法线 + Fresnel + 泡沫 + 雾）；③ 蒙皮顶点着色器 |
| 程序化建模 | 自行车（车架管件/轮/辐条/牙盘/链条）、鹈鹕（身体/双段脖子/头/喙/喉囊/翅膀/腿/蹼足/小帽）、画廊小屋全部代码生成 |
| 几何机构 | 真实齿比 `轮半径/牙盘半径 ≈ 3.82`，脚踏轨迹驱动鹈鹕双腿，踏频与速度联动 |
| 粒子系统 | InstancedMesh 海鸥群环绕扑翼 + Points 骑行浪花 |
| 昼夜循环 | 一键切换，光照/天空/海面/雾整体平滑过渡 |
| Web Audio | 合成海浪 + 速度风声 + 车铃 + 鹈鹕叫 + 捏闸声，无任何音频文件 |
| 交互 | OrbitControls 相机 + 点击鹈鹕触发叫声 + 空格捏闸 + 速度滑块 + 线框/环绕开关 |
| AI 生成素材 | 英雄区落日图、场景内画廊挂画、鹈鹕羽毛法线贴图、木板贴图（`assets/textures/`） |
| 纯代码兜底 | 木纹/天空渐变/粒子贴图用 Canvas 程序生成，AI 贴图加载失败也能完整运行 |

## 操作

- 拖动底部滑块调速（HUD 实时显示速度 / 踏频 / 里程）
- 点击鹈鹕：它会点头张嘴叫
- 空格：捏闸减速
- 顶栏：线框模式 / 自动环绕 / 昼夜切换 / 声音开关
- 下方画廊：点击任意卡片看大图

## 彩蛋

场景里有一座画廊小屋，墙上挂着 AI 生成的鹈鹕油画——和页面底部画廊区是同一张图。
