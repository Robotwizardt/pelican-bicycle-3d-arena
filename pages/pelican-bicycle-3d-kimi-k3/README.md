# 鹈鹕快递员 · Pelican Courier 3D

一只鹈鹕骑着自行车，在一片全程序化生成的山谷里送小鱼干。🦩🚲🐟

**打开方式**：直接用浏览器打开 `index.html` 即可（唯一外部依赖是 jsdelivr 上的 Three.js r160，需联网）。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` / `↑` | 蹬车加速 |
| `S` / `↓` | 刹车 |
| `A` / `D` | 转向 |
| `Space` | 跳起；冲上坡道会自动起飞 |
| 空中按住 `W` | 扑翼滑翔 |
| `R` | 重生 |
| `N` / `T` / `C` / `M` | 昼夜 / 下雨 / 镜头 / 声音 |
| 触屏 | 屏幕左中右三区 = 左转 / 蹬车 / 右转 |

## 玩法

- 收集发光的小鱼干（小地图上青色点），每 10 条触发一次庆祝；
- 橙色方块是坡道，冲上去就能起飞，空中按住 W 滑翔能飞更远；
- 昼夜切换后车头灯自动点亮；下雨不影响心情，只影响发型。

## 技术说明（全部程序化，无任何外部模型/贴图/音频）

- **Three.js r160**（importmap + jsdelivr ESM），无构建步骤；
- 鹈鹕、自行车、地形、树、云、鱼、坡道全部用程序化几何拼装（含 CatmullRom 曲线脖子、ExtrudeGeometry 翅膀、TubeGeometry 车架）；
- 双腿 **two-bone IK** 实时吸附到旋转脚踏上；
- 自研骑行物理：坡度加减速、滚动阻力、转向倾斜（roll）、坡道起跳、空中滑翔；
- 值噪声地形 + 顶点着色 + 斜坡采样，坡道嵌入地形并与物理高度函数一致；
- 自定义天空渐变 Shader、UnrealBloom 后处理、PCFSoft 阴影、昼夜平滑过渡、星空、雨粒子；
- WebAudio 全合成音效（风声随速度滤波、踏板咔哒、拾取琶音、落地闷响、下雨白噪声），无任何音频文件；
- 2D Canvas 雷达小地图、玻璃拟态 HUD、粒子爆裂/彩带；
- 已通过 Playwright (Edge) 实机验证：控制台 0 报错。
