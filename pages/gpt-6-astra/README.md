# Pelican Post · 骑进海风里

一只鹈鹕、一辆薄荷绿自行车、一座没有截止日期的小岛。

## 访问

- 已部署地址：https://wise-spire-twng.dataecho.ai/
- 这次使用匿名临时部署，服务端返回的到期时间是 **2026-10-01 10:35:49 UTC**，即 **2026-10-01 18:35:49 北京时间**。
- 认领链接和部署凭证保存在 `artifacts/deployment-private.json`。该文件未上传，且已被 `.gitignore` 排除。不要公开分享此文件。
- 若要持续保留同一地址，使用认领链接登录并完成站点认领，再按服务商规则管理。

## 内容

- 原创程序化鹈鹕模型：长喙与喉囊、护目镜、羽翼、眼睛眨动、随风围巾。
- 原创自行车模型：车架、辐条、挡泥板、车篮鲜花、行李、车灯；车轮、曲柄、踏板及双腿联动。
- 微缩海岸岛屿：环岛公路、灯塔、小屋、棕榈、草丛、海面波纹、帆船、海鸥和云朵。
- 白昼 / 月光模式，夜间灯塔与车灯、星星与萤火点。
- 鼠标或触屏环绕观察、缩放、镜头复位、速度调节、暂停、骑行里程。
- Web Audio 本地合成海浪、海鸥与自行车铃。音频只在用户主动操作后启动。
- 生成 1800 × 1400 PNG 海风明信片并下载。
- 桌面和手机布局、键盘操作、减少动态效果偏好、图形能力不足时的友好提示。

所有运行时依赖和字体均从本站加载，不使用远程模型、外部字体服务、追踪器或 API 密钥。

## 本地运行

需要兼容 Vite 8 的 Node.js；本项目使用 Node.js 24.18.0 构建。

```bash
npm ci
npm run dev
```

```bash
npm test
npm run build
npm run preview
```

`dist/` 是可独立部署的静态网站。Three.js 和所有资源已打包在内。

## 源码

- `src/main.js`：渲染器、灯光、镜头、交互、明信片和生命周期。
- `src/rider.js`：鹈鹕、自行车、踩踏运动学、围巾和铃铛反馈。
- `src/world.js`：岛屿、水面着色器、灯塔、植被、天空与夜景。
- `src/audio.js`：本地程序化声音。
- `src/ride-state.js`：速度、里程、圈数状态。
- `src/style.css`：响应式页面与日夜主题。
- `tests/ride-state.test.js` / `tests/scene.test.js`：Node.js 测试。
- `tests/browser-check.js`：Playwright 浏览器交互验证。
- `publish.mjs`：只上传 `dist/`，不会上传源码、测试、其他目录或部署凭证。

## 重新发布

首次可运行 `npm run build` 后执行 `node publish.mjs`。

已发布后，脚本不会自动创建另一个匿名站点。要更新同一地址，请先完成认领，再设置拥有该站点的 `DATAECHO_API_KEY` 环境变量并重新运行。发布脚本不会打印 API 密钥。
